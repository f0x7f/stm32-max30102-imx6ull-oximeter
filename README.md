# STM32-MAX30102-IMX6ULL 血氧心率监测系统

## 项目简介
本项目基于 STM32 驱动 MAX30102 光电心率血氧传感器，采集 PPG 光电容积脉搏波信号，通过串口传输至 IMX6ULL 嵌入式 Linux 开发板，最终通过 Qt 界面在 RGB 屏上实时显示心率、血氧数值与脉搏波形。

项目包含完整的 STM32 底层驱动、数据预处理算法、串口传输协议，可直接用于嵌入式课程设计、毕设基础工程，或二次开发。

## 硬件平台
- **主控单元**：STM32F103C8T6（STM32F103xB 系列）
- **传感器**：MAX30102 心率血氧传感器（I2C 接口）
- **上位机**：i.MX6ULL 嵌入式 Linux 开发板
- **显示**：RGB LCD 液晶屏
- **通信**：USART 串口（STM32 ↔ IMX6ULL）

## 软件架构
### STM32 端（本仓库）
1. **MAX30102 驱动层**：I2C 读写寄存器、FIFO 数据读取、模式配置、LED 电流控制
2. **数据处理层**：PPG 信号滤波、直流分量去除、心率与血氧值计算
3. **传输层**：串口数据打包发送，自定义帧协议保证数据可靠性
4. **主逻辑**：周期采集 → 算法计算 → 串口上传

### IMX6ULL 端（算法 QT上位机）
- 串口数据接收与解析
- 心率、血氧数值实时显示
- PPG 波形实时绘制
- 阈值告警、数据记录等扩展功能
